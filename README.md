# 📖 Overview

🧠 **SwarmAssist** is an AI-powered productivity platform that leverages a **Multi-Agent Swarm Architecture** to intelligently organize daily tasks while promoting user wellness.

Unlike traditional task managers, SwarmAssist enables multiple specialized AI agents to collaborate in real time, producing an optimized, explainable, and energy-aware schedule.

---

# ✨ Features

| Feature | Description |
|---------|-------------|
| 🤖 Multi-Agent AI | Specialized AI agents collaborate to create optimized schedules. |
| ⚡ Smart Prioritization | Automatically ranks tasks based on urgency and productivity. |
| 💙 Wellness Planning | Injects breaks, hydration reminders, and wellness activities. |
| 🎤 Voice Briefing | Reads the final schedule using browser speech synthesis. |
| 🔄 Fault-Tolerant AI | Uses timeout recovery to prevent UI blocking. |
| 📊 Explainable AI | Visualizes every AI agent's contribution. |
| 📱 Responsive UI | Modern interface built with React and Tailwind CSS. |
