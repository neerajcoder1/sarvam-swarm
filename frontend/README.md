# Sarvam Swarm Lite

**Your Personalized Life Agent Swarm** — a production-ready React + Vite dashboard replicating the TeamVibe Agentic AI Career Co-Pilot design system, adapted for personalized life planning.

## Stack

- React 19 + Vite 8
- Framer Motion
- Recharts
- Lucide React
- Tailwind CSS 4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## Features

- **248px sidebar** with brand, navigation, user card, and autonomous life mode controls
- **Flex grid layout** (1.52fr + 0.95fr) with hero card, readiness score, charts, and timeline
- **LiveAgentWidget** with 5 autonomous life agents (Orchestrator, Personalization, Task Executor, Recommendation, Voice Narrator)
- **Dark mode** via theme toggle (persisted to localStorage)
- **Responsive** breakpoints at 1050px and 650px
